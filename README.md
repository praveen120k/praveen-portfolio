# Praveen Kumar V, developer portfolio
React + TypeScript + Vite + Tailwind CSS + Framer Motion.

    npm install
    npm run dev        # http://localhost:5173
    npm run build      # type-check + production build to dist/
    npm run preview    # serve the production build locally

All content lives in `src/data/portfolio.ts`. Contact links, project GitHub/live URLs and the resume path are set there; empty values are hidden.
